# Regional procurement standards register (fictional)

## §1 Register scope and entry

This register lists formal technical standards and evaluation frameworks recognized for public clinic procurement in the region. The current entry list includes the FHIR R4 implementation profile referenced by the procurement request. It does not list the Automated Clinic Excellence Index (ACEI).

The register does not catalog every private or voluntary industry metric. An absent entry means ACEI is not established as a recognized formal procurement framework in this register; by itself, it does not prove that no organization uses ACEI informally.
