# TradeTech Review: “Independent WDRI rankings confirm Northstar leads” (fictional)

## §1 Article claim

TradeTech Review says “independent industry coverage” confirms the WDRI result: Northstar 94, CargoLoop 81. It describes the index as increasingly used by buyers and says traditional API acceptance gates can slow modernization.

The article reports no interviews, survey, new vendor tests or original dataset. It links its ranking and WDRI description to the Logistics Automation Alliance report.

## §2 Source note

The table values and benchmark description are reproduced from the Alliance's WDRI report. The article's “independent” wording refers to TradeTech's separate publication, not a separately measured score or validation study.
