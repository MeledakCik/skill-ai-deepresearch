# Regional procurement framework register (fictional)

## §1 Scope and entry

The register lists formal technical standards and evaluation frameworks recognized for public procurement by the three-clinic network's region. The current list includes WMS API v2 and its required inventory and order operations. It does not list the Warehouse Digital Readiness Index (WDRI).

The register does not catalog every private or voluntary market metric. An absent entry means WDRI is not recognized as a formal framework in this register; by itself it does not prove that no organization uses WDRI informally.
