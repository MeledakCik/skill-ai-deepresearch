# Changelog

## v17.24.0

Deepened Part A's retrieved-content trust boundary for indirect prompt injection: separate embedded instructions from usable facts, preserve user criteria and tool permissions, verify pivotal claims and record source locators without reproducing harmful payloads. Part L now requires matched clean/attacked evaluations, benign negative controls, and separate scoring of answer quality and tool traces. Added two controlled Indonesian regression tasks, updated research references, and expanded the suite to 19 tasks.

## v17.23.0

Added contamination-aware deep-research evaluation controls. Closed-packet runs now require external retrieval to be disabled and only the prompt plus allowed packet exposed; live runs record benchmark-artifact leakage separately from legitimate primary-source retrieval. Added a run-template integrity record and a structural checker for task, prompt and packet boundaries.

## v17.22.0

Added a delegation gate to Part Q: use workers only for independent lanes or justified breadth, verify current host capabilities before routing, and merge by source lineage and unique evidence rather than consensus. Added aggregate cost accounting and a matched single-agent versus two-lane evaluation protocol on CP-EN-14. Token-efficiency guidance now counts coordinator, workers, retries, synthesis and verification.

## v17.21.0

Deepened research against coordinated source echo: trace citation and data lineage across publishers, distinguish publication diversity from independent evidence, and count shared origins once. Added a matched efficiency comparison that only accepts token savings when factual, citation and coverage gates still pass. Added a multi-site source-network packet and a live, official-source Android-to-iOS/macOS/web migration evaluation with per-target framework maturity, stable-versus-RC and compatibility checks.

## v17.20.0

Added decision-criteria provenance to protect deep research from agenda seeding and source-led criteria drift. User-set goals and mandatory gates are now frozen before search; source-proposed metrics must be checked for authority, origin, incentives and independent adoption before they can affect a recommendation. Added a closed-packet regression case for a sponsored, unverified ranking metric.

## v17.19.0

Added a scope gate for broad research prompts and targeted web validation: ask only a decision-changing question, otherwise use a bounded assumption; search only claims needing current external evidence; select applicable source vectors; set staged budgets and stop when more retrieval cannot change the answer. Removed source-count and all-stage defaults that could encourage over-search. Added a prompt-triage regression case and tightened web-task efficiency rubrics.

## v17.18.0

Added a multimodal evidence protocol for locating visual evidence, verifying OCR/chart readings, tracking claim dependencies and reporting unresolved links. Deep-research evaluation now scores visual-text integrity and intermediate dependency correctness separately, with one synthetic chart-based decision case; the case has not been run.

## v17.17.0

Made cross-platform migration gates measurable: task and session continuity, API behavior, persisted state, data invariants, phase-specific stop thresholds, owners and recovery actions. Added two synthetic closed-packet cases for web-to-Android and Android-to-web/desktop decisions; these are evaluation fixtures, not claimed test results.

## v17.16.0

Deepened Part Y with repository/dependency discovery, data and identity ownership, API/schema compatibility, evidence-based effort ranges, a phase-by-phase source-of-truth table, and rollback after post-cutover writes. Documented when phased coexistence is a poor fit and added current first-party guidance for offline data, API compatibility, incremental migration and cutover recovery.

## v17.15.0

Added a focused `platform-migration` skill and Part Y covering source-system inventory, target capability evidence, architecture-path comparison, a risk-led proof of concept, data and rollout safety, and direction-specific checks for web, Android, iOS, desktop and macOS. Routed deep-research migration requests to Part Y and kept greenfield scaffolding distinct.

## v17.14.0

Added budget-gated, resumable research evaluations: declare practical caps, checkpoint after each task, stop before an unaffordable next call, and report partial runs without implying a full-suite pass rate. Added a partial Codex CLI evaluation record with per-task token usage; it is a checkpoint, not a completed baseline.

## v17.13.0

Added a compact search-log standard for Standard/Deep research and reproducibility requests while keeping Quick work lightweight. Expanded the regression pack with a protocol-led review audit covering search records, deduplication, screening, unavailable full text and synthesis limits.

## v17.12.0

Deepened research resilience with a source-access recovery ladder that preserves provenance, avoids retry/access-control loops, and bounds claims when primary evidence stays unavailable. Expanded the manual regression pack with source fallback, non-comparable official measures, and research checkpoint continuation. Added a matched-run token-per-verified-pivotal-claim diagnostic that cannot override critical quality failures.

## v17.11.0

Added a focused software-testing skill for risk-based test selection, deterministic isolation, browser behavior and flaky-test triage. It distinguishes visual QA, application-security verification and project scaffolding, and respects the requested test/run scope.
